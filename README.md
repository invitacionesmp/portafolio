# Portafolio · Ivan Solis

Sitio estático (HTML, CSS y JavaScript), sin dependencias.

## Estructura
- `index.html`: textos, SEO y enlaces de contacto.
- `js/main.js`: lista `works` con los trabajos (videos en `assets/video/`, imágenes en `assets/img/`).
- `assets/img/og.jpg`: imagen de previsualización al compartir el enlace.

## Publicar en GitHub Pages
1. Sube el contenido de esta carpeta a la raíz del repositorio `invitacionesmp/portafolio`.
2. Settings > Pages > "Deploy from a branch" > rama `main`, carpeta `/ (root)`.
3. Queda en https://invitacionesmp.github.io/portafolio/
